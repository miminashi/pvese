## 前提・目的

ユーザ依頼「tx1320 の RAID をいちど初期化してから、PVE インストールまでおこなってください」を、確立済みの標準経路 (iPXE-CD、3/3 + sonnet 自律 10/10 実証済み) で実行する。

- 背景: training-tx1320 は別拠点設置の一時マシン。iRMC USB redirector の累積劣化を iPXE-CD 経路が回避する。
- RAID 初期化方式: ユーザ選択により **BIOS HII KVM での明示的 RAID Clear (標準経路)** を採用。install 中の preseed `partman/early_command` の storcli が RAID10 を delete+create 再構築するため、最終 RAID10 は install が作成する。
- 目的: Debian 13 + HW RAID10 + PVE 9.x (web UI 200) を物理操作なしで構築する。

## 再現方法

> 詳細手順は [実装プラン](attachment/2026-06-10_212639_tx1320_raid_clear_pve_e2e/plan.md) を参照。以下は実際に実行したコマンド列。

### Step 1: BIOS HII KVM で RAID Clear

```sh
# BIOS Setup + 健全 KVM 状態へ復旧 (host ForceOff → Manager.Reset → boot-override BiosSetup + on → POST 待ち)
./oplog.sh ./scripts/irmc-kvm-recover.sh config/training_tx1320.yml tmp/cbd3dbe1/recover-bios.jpg

# 永続 KVM サーバ起動 (=== KVM server READY === を待つ)
.venv/bin/python scripts/irmc-kvm/server.py --bmc-ip 10.254.254.9 --bmc-user claude --bmc-pass Claude123 --srv-dir tmp/cbd3dbe1/srv
```

`tmp/cbd3dbe1/srv/in/NNN.cmd` を投入して per-key 操作 (各 shot をサブエージェントで画像分析):

1. `press ArrowRight 2000` + `shot tab.png` → Advanced タブ着地確認 (size=17919, caret_y=102)
2. `navy 393 caret 25 1500` + `shot avago_row.png` → AVAGO 行 adaptive 着地 (size=18051, caret_y=393、help "Manage RAID Controller Configurations.")
3. `Enter` → AVAGO dashboard (**Virtual Drives: 1 / Drive Groups: 1 / Drives: 4 / Status [Optimal]** = 既存 VD 存在を確認)
4. `Enter` → Main Menu (5項目) → `Enter` → Config Mgmt (VD 有り = 2項目: View Drive Group Properties / Clear Configuration)
5. `ArrowDown 1` → `Clear Configuration` 行確認 (size=10135, help "Deletes all existing configurations on the RAID controller.")
6. modal commit 1ファイル: `press Enter 3000` (dialog, size=11383) → `mouse 80 240` → `ArrowDown→Enter`×3 (No→Confirm→Enabled→Yes) → commit → c4_committed.png (size=9462, "The operation has been performed successfully")
7. `Enter` (►OK) → `Escape` (Main Menu) → `keyrepeat ArrowDown 2` (VDM 行) → `Enter` → `shot vdm.png` → **size=9758 = "no Virtual Drives currently available" = Clear 成功**
8. `quit`

### Step 2-3: iPXE-CD deploy + install 監視

```sh
./oplog.sh ./scripts/irmc-ipxe-cd-deploy.sh config/training_tx1320.yml ipxe-tx1320.iso
# → DisconnectCD(400 無害) → CDImage NFS(200) → VirtualMediaServiceRestart(204) → On → ConnectCD(204) → ForceOff → boot-override Cd UEFI → On

.venv/bin/python scripts/sol-monitor.py --bmc-ip 10.254.254.9 --bmc-user claude --bmc-pass Claude123 \
    --log-file tmp/cbd3dbe1/install.log --timeout 2400 --powerstate-interval 30
# stage 進行: DETECTING_NETWORK(2.3min) → CONFIGURING_APT(3.3min) → INSTALLING_SOFTWARE(10.4min) → INSTALLING_GRUB(12.5min) → POWER_DOWN(13.6min) → Off
```

### Step 4-5: disk boot + eno2 IP 特定

```sh
# (env を export するラッパー経由)
./oplog.sh ./scripts/bmc-power.sh boot-override 10.254.254.9 claude Claude123 Hdd UEFI
./oplog.sh ./scripts/bmc-power.sh on 10.254.254.9 claude Claude123

# ping-sweep で neigh を充填 → eno2 MAC で IP 抽出
sh tmp/cbd3dbe1/find-ip.sh   # → 10.254.254.5 (install 直後)
```

### Step 6-7: PVE 通しセットアップ + 検証

```sh
./oplog.sh ./scripts/tx1320-pve-setup.sh config/training_tx1320.yml 10.254.254.5
# wait_ssh が eno2 lease 変動 (.5→.16) を MAC 再 discovery で追従 → live hostname tx1320 採用
# → pre-reboot(PVE repo+kernel 119MB) → reboot → post-reboot(proxmox-ve) → reboot → 検証

# 独立検証
ssh -F ssh/config -o StrictHostKeyChecking=no -o UserKnownHostsFile=/dev/null root@10.254.254.16 "pveversion; systemctl is-active pveproxy pvedaemon pve-cluster"
curl -sk --max-time 15 https://10.254.254.16:8006 -o /dev/null -w '%{http_code}\n'
```

## 確認事項・所感

- 標準経路どおり決定論的に完遂。脆弱リンクの BIOS HII RAID Clear も検証付き手順 + per-key サブエージェント分析で一発成功 (ArrowRight ドロップなし)。指紋値 (tab=17919 / avago=18051 / clearrow=10135 / dialog=11383 / committed=9462 / vdm=9758) は過去 10-run と完全一致。
- eno2 lease は予想どおり最終 reboot 群で変動 (.5→.16)。`tx1320-pve-setup.sh` の wait_ssh + MAC 再 discovery が無人で追従し、固定 IP 待ちの取り逃しを回避した。
- RAID10 は storcli 直読で `Optl 1.635 TB` を裏取り (sda 1.6T 単一 + LVM の傍証も一致)。
- 既知の無害ノイズ: deploy 中の DisconnectCD HTTP400 / PowerOn `ActionParameterValueNotInList`、PVE install の `W: Tried to start delayed item` 大量警告。いずれもガード済み。
