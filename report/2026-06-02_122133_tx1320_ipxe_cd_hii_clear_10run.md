## 前提・目的

- **背景**: training-tx1320 への OS install 経路として VirtualMedia iPXE-CD (2026-05-31 確立、USB redirector 劣化を `VirtualMediaServiceRestart` で回避) が確立済み。また 2026-06-02 (d0a59391) に BIOS HII KVM 経由の RAID10 作成 / Clear が実証された。
- **目的**: OS install を **10 回反復**して堅牢性を検証し、試行ごとの知見でスキルを改善する。**各試行前に BIOS メニューから RAID を初期化して初期状態を揃える**。要所で KVM スクリーンショットを取得する。
- **ユーザ確定事項**:
  - install 経路 = VirtualMedia iPXE-CD
  - 各試行前の RAID 初期化 = **BIOS HII で Clear Configuration（削除）のみ**。RAID10 の作成は install 中の storcli が担当（実証済みフローを崩さない。Clear のみの方が高速）。
  - 改善対象スキル = `irmc-bios-raid`（Clear 手順）と `pxe-deploy`（iPXE-CD install）

## 各 run の要点

**Run 01（手順確立）**: per-key + スクショ検証で BIOS HII Clear の手順を一段ずつ確認。`Main → Advanced → AVAGO MegaRAID (ArrowDown×14) → Main Menu → Configuration Management → Clear Configuration → 確認ダイアログ` の commit recipe（`mouse 80 240` でフォーカス → `No→ArrowDown wrap→Confirm` → ドロップダウンで `Enabled` → `Yes`）が**初回で成功**。Virtual Drive Management で「no Virtual Drives」を裏取り。install では SOL log に `raid10-setup creating RAID10 with drives=252:0..3` → `sd [sda] 1.64 TiB` → `RAID10 created` → `0/0 RAID10 Optl 1.635 TB` を確認し、**disk が /dev/sda であることを実機確定**。

**Run 02（streamline）**: Clear を 4 コマンドファイル（nav / enter-chain / commit / verify）に集約。全チェックポイントのスクショ byte-size が run 01 と完全一致。

**Run 03〜10（統合1ファイル）**: Clear 全工程を 1 コマンドファイル (`clear-all.cmd`) にまとめて投入。5 つのチェックポイント (`c1_avago`=18051B / `c2_clear_row`=10135B / `c3_dialog`=11383B / `c4_committed`=9462B / `c5_vdm_verify`=9758B) が **8 run 連続で同一 byte-size**。Run 09 のみ、コマンド投入の遅延で初回 KVM セッションが idle-timeout（3600s）に達し再起動したが、host は BIOS Setup に留まり install への影響なし。

全 run 共通: deploy は `irmc-ipxe-cd-deploy.sh` が DisconnectCD→config(NFS)→VirtualMediaServiceRestart→On→ConnectCD→ForceOff→boot-override Cd UEFI→On を実行（再試行 0/10）。install 完了は **auto-poweroff (PowerState=Off)** をゲートに判定し、nginx の preseed/storcli/phonehome GET を進捗の裏取りに併用（run 01-06 は phonehome-setup GET も観測、run 07-10 は nginx 監視通知が出ず poweroff + 後述の SSH RAID10 検証で完了確認）。最終的な成否は **installed system への SSH 到達 + `storcli /c0/vall = RAID10 Optl 1.635 TB`** で確定（10/10）。disk boot 後 eno2 dark-net IP を `ip neigh | grep <MAC>` で特定。

## BIOS HII Clear Configuration 手順 再現性 総合判定

- **10/10 成功・100% 決定論再現**。Run 01 で per-key 確立 → Run 02 で 4-file streamline → Run 03 以降は単一コマンドファイルで無人実行可能と確定。
- **高 latency (94〜183ms) でも `keyrepeat ... 1600` が 1:1 で着地**（過剰登録なし）。`keyrepeat ArrowDown 14 1600` が毎回 AVAGO 行 (caret_y=393) に正確着地。
- **スクショ byte-size が画面遷移の信頼できる指紋**（locator capture mode、10 run 全一致）。size 一致で遷移成功と判定でき、per-key の対話的フィードバックは不要だった。
- 落とし穴: KVM 永続セッションの `--idle-timeout` 内に必ずコマンド投入すること（Run 09 で投入遅延 → セッション期限切れ → 再起動）。

## iPXE-CD install 総合判定

- **deploy 再試行 0/10** — VirtualMediaServiceRestart で USB redirector 劣化を毎回回避。10 連続 deploy で「メディア未提示」ゼロ（Phase 15-18 の壁は本経路では再現せず）。
- **#15 (d-i netcfg dual-NIC stuck) 0/10** — 本検証の embed ipxe.efi は旧 `interface=auto` 版だったが一度も発生せず。#15 がタイミング依存の非決定的事象であることを裏付ける（PXE-TFTP 経路の前回 10-run では同じ `interface=auto` で 30% 発生）。**ただし決定論的解消の `interface=eno1` 固定は引き続き推奨**。
- install ~8-10min（preseed→phonehome→poweroff）、総時間 ~25-30min/run。
- VGA は kernel cmdline `console=ttyS0` のため install 中ブランク（d-i は SOL に出力）。進捗の一次情報は **SOL log + nginx access.log の preseed/storcli/phonehome GET**。installed system は VGA tty1 に getty（login プロンプト撮影可）。

## 再現方法

```sh
# 共通 env (bmc-power.sh 呼び出し前に export; 本 run では wrapper 内で設定)
#   BMC_SCHEME=https / BMC_CURL_OPTS="--ciphers DEFAULT@SECLEVEL=0" / POWER_ON_RESET_TYPE=On
#   BMC_PATCH_REQUIRES_ETAG=1 / BMC_BOOT_OVERRIDE_NO_DISABLED=1

# 1) BIOS Setup へ起動 (forceoff → boot-override BiosSetup UEFI → on)
sh tmp/<sid>/boot-bios.sh          # 約100s 待って OEM screenshot で BIOS Main 確認

# 2) KVM 永続サーバ起動 → 統合 Clear コマンド投入
.venv/bin/python scripts/irmc-kvm/server.py --bmc-ip 10.254.254.9 \
    --bmc-user claude --bmc-pass Claude123 --srv-dir tmp/<sid>/runNN/srv --idle-timeout 3600
cp tmp/<sid>/clear-all.cmd tmp/<sid>/runNN/srv/in/001.cmd
#   → c4_committed (size 9462) で Clear 成功、c5_vdm_verify (size 9758) で「no Virtual Drives」確認
#   手順詳細は SKILL.md「2026-06-02 (r10hiicd): Clear Configuration は単一コマンドファイルで…」節

# 3) iPXE-CD deploy
./scripts/irmc-ipxe-cd-deploy.sh config/training_tx1320.yml ipxe-tx1320.iso

# 4) 完了待ち (auto-poweroff) + nginx で preseed/storcli/phonehome GET 確認
sh tmp/<sid>/poll-off.sh

# 5) disk boot → eno2 IP 特定 → SSH 検証
sh tmp/<sid>/disk-boot.sh
sh tmp/<sid>/discover-host.sh       # ip neigh | grep 4c:52:62:14:de:f0
sh tmp/<sid>/verify-run.sh <ip>     # ssh-keygen -R → scp → storcli /c0/vall show
```
