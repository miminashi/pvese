## 前提・目的

- **背景**: トレーニング用に Fujitsu PRIMERGY TX1320 M3 が 10.254.254.9 に一時設置された (BMC は iRMC S4)。pvese プロジェクトは Supermicro X11DPU/X10DRT-P + DELL R320/R430 のみ対応していたため、Fujitsu/iRMC の 3 ベンダー目を追加する必要があった。
- **目的**:
  1. 対応機種一覧に iRMC S4 (新 `bmc_type=irmc`) を追加し、最低限の電源操作を `bmc-power.sh` で動かせる状態にする
  2. iRMC S4 の BIOS / RAID 操作プロトコルを調査し、`irmc-bios-raid` skill として手順化する
  3. SAS HDD 900GB × 4 を HW RAID10 (実効 1.8 TB) で構成できる状態にする
  4. SOL (Serial Over LAN) の利用可否を本セッション中に確定する
  5. クラスタ・LINSTOR には参加させない (一時設置のため)
- **本セッションのスコープ外** (次セッションで実施予定):
  - Virtual Media / preseed install 自動化スクリプト
  - Debian + Proxmox VE のインストール
  - HTML5 KVM 自動操作 (Playwright)

## 環境情報

- マシン: Fujitsu PRIMERGY TX1320 M3 / MainBoard D3373 / BIOS V5.0.0.11 R1.22.0
- BMC: iRMC S4 / FirmwareVersion 9.08F / SDR 3.16
- BMC ユーザ: claude (index 4, RoleId Administrator, LAN/Serial Administrator)
- ネットワーク: 10.254.254.9 (BMC) / OS 側は DHCP (192.168.33.0/24 + 10.254.254.0/24, 後者は実体 10.0.0.0/8)
- 物理ディスク: SAS HDD 900GB × 4 (Drive Slot HDD0-3 全て SignalStatus OK)
- HW RAID コントローラ: PCIe slot 1-4 は EmptyOrNotInstalled → onboard / mezzanine 接続 (具体 Model は Redfish からは取得不可)
- ライセンス: KVM ✓ / MEDIA ✓ (Permanent) — eLCM なし
- 配置: 別拠点・一時設置・クラスタ非参加

### Phase 2: 実機調査

詳細は [probe-summary.md](attachment/2026-05-16_095827_tx1320_m3_add/probe-summary.md) 参照。要点:

| 項目 | 結果 |
|------|------|
| HTTPS 接続性 | default ciphers / `--tls-max 1.2` で curl exit 35 → **`--ciphers DEFAULT@SECLEVEL=0` で成功** |
| HTTP 接続性 | anonymous で `/redfish/v1/` のみ取得可 (認証付きは 404) |
| Redfish version | 1.0.5 + Fujitsu OEM (`ts_fujitsu`) 拡張 |
| Systems パス | `/redfish/v1/Systems/0` (1 台) |
| **`#ComputerSystem.Reset` AllowableValues** | **`On` 不在** (`ForceOff` / `ForceRestart` / `Nmi` / `PushPowerButton` のみ) |
| Bios.Attributes | **空 `{}`** (OEM の WinSCU XML 経由で操作) |
| Storage Members | **空 `[]`** (Redfish 経由 RAID 操作不可) |
| eLCM | HTTP 403 (ライセンスなし) |
| HTML5 KVM | `Html5Enabled: true` (ライセンス KVM ✓ / MEDIA ✓) |
| IPMI LAN+ | claude (index 4) で全 cipher 通過 |
| **SOL 利用可否** ★ | **利用可能** — ただし `ipmitool ... sol payload enable 2 4` で claude のチャンネル 2 payload を事前有効化必須 |
| HW RAID コントローラ機種 | 未確定 (Redfish では Storage 空) — iRMC Web UI Storage タブまたは BIOS RAID Util で目視確認が必要 |
| 物理ディスク数 | 4 本 (HDD0-3 全 SignalStatus OK) |
| 物理ディスクのセクタサイズ | Redfish では取得不可 — BIOS RAID Util から認識される/されないで判定 |

### Phase 3: `scripts/bmc-power.sh` の iRMC S4 対応

環境変数で URL スキーム / curl オプション / 電源 On アクションを可変化:

```sh
: "${BMC_SCHEME:=https}"
: "${BMC_CURL_OPTS:=}"
: "${POWER_ON_RESET_TYPE:=On}"
```

`redfish_get/post/patch` の URL を `${BMC_SCHEME}://...` に変更し、`${BMC_CURL_OPTS}` を curl 引数に追加。`cmd_on` / `cmd_cycle` の ResetType を `${POWER_ON_RESET_TYPE}` で展開。

加えて `get_system_path()` で iRMC が JSON `/` を `\/` でエスケープする問題に対応するため、`tr -d '\\'` でレスポンスを正規化してから sed パース。

```sh
# iRMC で動作確認
$ BMC_SCHEME=https BMC_CURL_OPTS='--ciphers DEFAULT@SECLEVEL=0' \
    ./scripts/bmc-power.sh status 10.254.254.9 claude Claude123
On

# 既存機種の回帰なし確認
$ ./scripts/bmc-power.sh status 10.10.10.24 claude Claude123    # Supermicro 4号機
Off
$ ./scripts/bmc-power.sh status 10.10.10.27 claude Claude123    # iDRAC7 7号機
Off
$ ./scripts/bmc-power.sh status 10.10.10.35 claude Claude123    # iDRAC8 15号機
On
```

→ 既存 Supermicro / iDRAC の動作に影響なし。

### Phase 8: RAID10 構成

実機調査の結果、以下が判明したため **RAID10 の実構成は本セッション内では完了させず、手動操作引き継ぎ** とした:

- Redfish Storage Members 空 + eLCM ライセンスなし → Redfish 経由の自動 RAID 操作は不可
- iRMC Web UI は Basic Auth では form セッションが取れない (Cookie ベース form login 必須)
- HTML5 KVM 自動操作 (form login 解析 + KVM canvas 操作) の実装は本セッション規模を超える
- → **skill (`irmc-bios-raid raid status/create-r10/delete`) は手動操作のガイドとして提供**、実構成はガイドに従って後日実施

物理ディスク 4 本 (HDD0-3) は SignalStatus OK で OEM ComponentStatus 経由で確認済み。セクタサイズは BIOS RAID Configuration Utility 起動時に判定 → 必要なら OpenWrt rescue で sg_format。

`openwrt-rescue` skill 化は実機検証が無いため見送り。

## 再現方法

### bmc-power.sh の iRMC 動作確認
```sh
BMC_SCHEME=https BMC_CURL_OPTS='--ciphers DEFAULT@SECLEVEL=0' \
    ./scripts/bmc-power.sh status 10.254.254.9 claude Claude123
```

### Redfish 探索
```sh
curl -sk --ciphers 'DEFAULT@SECLEVEL=0' -u claude:Claude123 \
    https://10.254.254.9/redfish/v1/Systems/0
```

### SOL 利用 (初回のみ payload enable)
```sh
ipmitool -I lanplus -H 10.254.254.9 -U claude -P Claude123 sol payload enable 2 4
ipmitool -I lanplus -H 10.254.254.9 -U claude -P Claude123 sol activate
# 終了は ~. (チルダ + ピリオド)
```
