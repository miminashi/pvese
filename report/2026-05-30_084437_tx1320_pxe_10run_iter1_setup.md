## 新落とし穴 (Run 1 で判明)

1. **bmc-power.sh boot-override が rc=52**: `redfish_patch` の `curl -skL` の `-L` フラグが PATCH と組み合わさって curl error 52 (empty reply)。対策: 直接 `curl -sk` (no `-L`) で PATCH。SKILL.md に #10 として追加
2. **irmc-virtualmedia.sh disconnect-cd が 400 エラー**: iRMC FW 9.69F で OEM action 名変更。PXE 経路では `IsAnyVirtualMediaActive: false` ならスキップ可。SKILL.md に #11 として追加
3. **eno2 DHCP IP が変動** (Phase 19: 10.254.254.4 → Run 1: 10.254.254.6): dark-net DHCP はリース固定なし。毎回 `ip neigh | grep <MAC>` で特定が必須。SKILL.md に #12 として追加
4. **ssh/config Host マッチ漏れ**: `training-tx1320` Host の HostName が 10.254.254.4 固定で動的 IP にマッチしない → Permission denied。対策: `Host 10.254.254.*` ワイルドカードを ssh/config に追加。SKILL.md に #13 として追加
5. **OpenWrt SSH が全拠点から拒否**: Port 22 refused。proxy として TX1320 installed system 経由 (sshpass) か local ARP テーブルで代替。preflight の Check 3 は TFTP テスト (atftp from TX1320) で代替
