## 再現方法

### Phase 1: 設定ファイル整備

`config/server7.yml` ベース、ただし下記を 4-6号機 (X11DPU) と同じパターンに変更:

```yaml
static_ip: 10.10.10.214      # / 10.10.10.215
static_netmask: 8
static_iface: eno2           # LAN2 = mgmt
dhcp_iface: eno1             # LAN1 = DHCP/インターネット
disk: /dev/sda
bmc_type: idrac
bmc_ip: 10.10.10.34          # / 10.10.10.35
bmc_user: claude
bmc_pass: Claude123
bmc_ssh_key: ssh/idrac_rsa
idrac_fw_version: "2.63.60.61"  # 14号機
idrac_fw_version: "2.85.85.85"  # 15号機
serial_unit: 0               # SerialPortAddress=Serial1Com2Serial2Com1 → ttyS0
```

### Phase 2: SSH 設定整備

```sh
# ssh/config に idrac14, idrac15, pve14, pve15 のエントリを追加
# scripts/idrac-virtualmedia.sh の resolve_idrac_host() に 10.10.10.34/35 ケースを追加
```

iDRAC ブートストラップは `tmp/r4301415/idrac_bootstrap.py` (paramiko password → `racadm sshpkauth -i 3 -k 1` で鍵登録 → `racadm set iDRAC.IPMILan.Enable Enabled`)。 **claude ユーザ index = 3** (7-9号機と同じ、root が index 2)。

### Phase 3: iDRAC 疎通・FW 取得

両機とも `ssh -F ssh/config idrac<N> racadm getsysinfo` で正常応答。FW バージョンを config に記録。

### Phase 4: BIOS / RAID 確認

両機ともデフォルト確認:
- `SerialPortAddress=Serial1Com2Serial2Com1` → serial_unit=0 確定
- `SerialComm=OnConRedirAuto`, `RedirAfterBoot=Enabled` (修正不要)
- 14号機: BootMode=Uefi (出荷時より UEFI)
- 15号機: BootMode=Bios → **racadm で Uefi に変更** + jobqueue pwrcycle で適用 (iDRAC7+R320 の禁忌 = UefiBootSeq 破壊事例とは異なり、iDRAC8+R430 では安全に変更できた)
- 両機とも VD 未構成

#### RAID-1 VD 作成 (Bay 0+1)

```sh
ssh -F ssh/config idrac<N> racadm raid clearconfig:RAID.Integrated.1-1
ssh -F ssh/config idrac<N> racadm raid createvd:RAID.Integrated.1-1 -rl r1 \
  -pdkey:Disk.Bay.0:Enclosure.Internal.0-1:RAID.Integrated.1-1,Disk.Bay.1:Enclosure.Internal.0-1:RAID.Integrated.1-1 \
  -name OS_RAID1
ssh -F ssh/config idrac<N> racadm jobqueue create RAID.Integrated.1-1 -s TIME_NOW -r pwrcycle
```

**Note**: iDRAC8 では `racadm raid clearforeignconfig` は存在しない。`clearconfig` を使う。

### Phase 5: OS インストール (15号機)

1. preseed-server15.cfg を `preseed-server8.cfg` ベースで作成
2. ISO リマスター (`remaster-debian-iso.sh --serial-unit=0`)
3. VirtualMedia mount (`idrac-virtualmedia.sh mount`) + boot-once VCD-DVD + power on
4. Debian preseed install (poweroff 完了)
5. SOL でログイン (root/password) → SSH 鍵配置 + PermitRootLogin yes + sudoers
6. SSH 接続後、interfaces を eno2=mgmt, eno1=DHCP に書き換え
7. `dhcpcd -1 -t 30 eno1` で 192.168.39.114 取得
8. **clock 修正** (preseed `clock-setup/ntp false` で RTC が 2001 年 → date -s で 2026-05-11 に修正、apt の GPG 検証エラー回避)
9. `pre-pve-setup.sh --dhcp-iface eno1 --static-gw 10.10.10.1 --codename trixie`
10. `pve-setup-remote.sh --phase pre-reboot ...` + reboot + `--phase post-reboot ...`
11. `pve-bridge-setup.sh --static-iface eno2 --static-ip 10.10.10.215/8 --dhcp-iface eno1`

最終状態:
- pve-manager/9.1.9 + kernel 7.0.2-2-pve
- vmbr0: 10.10.10.215/8
- vmbr1: 192.168.39.114/24 (DHCP)
- default route via 192.168.39.1

## 結果と知見

### 達成

- ✅ 14号機 iDRAC 疎通 + SSH 鍵認証 + IPMI LAN 有効化
- ✅ 15号機 iDRAC 疎通 + SSH 鍵認証 + IPMI LAN 有効化
- ✅ 15号機 BIOS→UEFI 変更 (racadm 経由で安全に動作)
- ✅ 15号機 PERC H730 で OS_RAID1 (Bay 0+1) 作成
- ✅ 15号機 Debian 13.3 + PVE 9.1.9 + vmbr0/vmbr1 構築完了
- ❌ 14号機 OS インストール **未完了** (PERC H730P 問題、別 issue #63 で対応)
  - Bay 0+1 で作成した RAID-1 が BGI 26% で完全停滞 (Power on/off 関係なし)
  - Bay 2+3 で再作成を試みるも `createvd` ジョブが PR21 (Job failed) で 2 回連続失敗
  - PERC H730P controller か backplane の問題と推定。Disk 単体テスト・PERC FW アップグレード等の深掘り診断が必要

### 重要な知見

1. **R430 + iDRAC8 と R320 + iDRAC7 の差分**:
   - iDRAC8 では `racadm raid clearforeignconfig` 不在 → `clearconfig` を使う
   - iDRAC8 + R430 では `racadm set BIOS.BiosBootSettings.BootMode Uefi` が **安全**に動作 (R320/iDRAC7 では UefiBootSeq 破壊事例があり禁忌)
   - iDRAC dedicated mode (R430 デフォルト) は host LAN ポートと独立。R320 は LOM1 shared。
   - SSH KEX: iDRAC FW 2.63 (14号機) と 2.85 (15号機) のいずれもデフォルト KEX で paramiko 接続可能

2. **NIC 配線が 4-6号機 (X11DPU) と同じ**:
   - LAN1 (eno1) = 192.168.39.0/24 DHCP
   - LAN2 (eno2) = 10.10.10.0/8 mgmt
   - **7-9号機 (R320) とは逆**。R430 用 preseed/config では `static_iface: eno2`, `dhcp_iface: eno1` を使う。

3. **Debian 13 minimal install の DHCP client**:
   - `isc-dhcp-client` がデフォルトで入っていない (preseed `install-recommends false` のため)
   - 代わりに `dhcpcd-base` が入っており、`/usr/sbin/dhcpcd -1 -t 30 <iface>` で取得可能
   - pre-pve-setup.sh の Step 7 で `isc-dhcp-client` を後追いインストールするが、Step 3 の `ifup` には dhclient が必要なため、最初に `dhcpcd` で IPv4 を取得しておく必要あり

4. **iDRAC RTC が 2001 年のまま**: 15号機の iDRAC RTC が `Mon Jan 1 2001` だったため、Debian 起動後の system clock も過去 (2025-09-04) になり、apt の GPG 検証で「Not live until 2026-XX」エラー。`date -s '2026-05-11 ...' && hwclock --systohc` で修正必要。

5. **PERC H730P での BGI 停滞 (14号機)**: Bay 0+1 で RAID-1 作成後、BGI 26% で進捗が完全停止 (Power on/off に関係なく)。Bay 0 or Bay 1 のディスク不良の可能性。別 disk pair (Bay 2+3) で再構成中。
