## 未完了 / 次セッション課題

### 1. Select RAID Level 到達手段の抜本的方針転換 (最優先)

本セッションで以下 **全 9 経路が失敗** したため、 Aptio HII KVM 経路では RAID 10 自動化が不可能と確定:

| 経路 | 試行 | 結果 |
|------|------|------|
| ArrowDown / ArrowUp / End / PageDown / Home / PageUp | iter_09, iter_09b | 全て y=128 をスキップ |
| Tab / Shift+Tab | iter_09b | 完全無反応 (Aptio 非対応) |
| Mouse click (canvas at x=50/200/300, y=128) | iter_09b | Playwright canvas click が Aptio に届かない |
| Enter on form_open (cursor y=88) | iter_09b T1 | Save Configuration dialog open (RAID Level submenu ではない) |
| Profile-based VD (Cfg Mgmt 別 item) | iter_09c | RAID 0/1/5/6 のみ、 RAID 10 profile 不在 |

**次セッションで試す候補** (優先順):

1. **LSI Software RAID Utility** (Advanced tab y=406) を試す
   - AVAGO MegaRAID と別 controller の HII の可能性
   - もし AVAGO と同じ controller を別 UI で操作するなら RAID 10 メニューが異なる可能性
   - ただし training-tx1320 の controller は LSI SAS3008 系 hardware RAID で、 「LSI Software RAID」は softRAID で別物の可能性高い
   - リスク: 低 (失敗しても無害、 ~ 15 min で検証可能)

2. **iRMC OEM Redfish 探索**
   - TX1320 は eLCM なしだが、 `/redfish/v1/Systems/0/Storage` には controller info あり (`bmc-power.sh` で取得可能)
   - OEM endpoint `/redfish/v1/Oem/ts_fujitsu/...` 配下に RAID 設定 panel が隠れている可能性
   - ただし FW 9.08F は old version で OEM Redfish は基本機能のみと想定
   - リスク: 低 (全 endpoint scan で ~ 30 min)

3. **2 段階 RAID 1 + RAID 0 stripe (RAID 10 ≒ RAID 1+0)**
   - Profile-based で RAID 1 を 2 つ作成 → AVAGO が RAID 1 VD を RAID 0 でストライプする機能を提供しているか確認
   - typical MegaRAID では RAID 10 は Create VD の中で 「Span 2」 として 1 step で作成、 2 段階構成は通常サポートされない
   - リスク: 中 (失敗する可能性高い、 ただし試行コストは ~ 30 min)

4. **キーボードイベント raw injection (Playwright bypass)**
   - 現在 `vp.keyboard.press("Tab")` で Aptio に届いていない原因の分析
   - iRMC KVM の HTML5 client は keyboard event を Java applet 互換の protocol に変換していると想定 → Tab が特殊扱いされている可能性
   - `vp.keyboard.down("Tab")` + `vp.keyboard.up("Tab")` の分解送信、 `KeyboardEvent` dispatch、 `Ctrl+I` (Tab の ASCII 等価) などを試行
   - リスク: 高 (root cause が iRMC client の仕様の場合、 突破困難)

5. **MEGACLI (OS 後) アプローチ**
   - circular (OS install には RAID 必要、 RAID 作成には OS 必要) — ただし install media で live CLI を起動して MEGACLI で RAID 10 作成 → 再起動して OS install という 2 段階アプローチは可能
   - リスク: 中 (live CLI 起動と MEGACLI 入手の手間あり)

6. **ユーザ手動完遂 (fallback)**
   - iRMC KVM Web UI を ブラウザで開いて、 mouse でクリックして Select RAID Level (y=128) に到達できれば、 そこで手動で RAID 10 を選択
   - **本セッションで mouse click が Aptio に届かなかった理由**: Playwright headless Chromium の canvas click は実際の mouse event ではなく JS dispatch であるため。 ブラウザ手動 click は本物の mouse event のため Aptio が反応する可能性
   - リスク: 低 (失敗しても無害、 ~ 5 min で検証可能)

**推奨アプローチ**: まず 6 (手動 click) で「ブラウザ手動 click が Aptio に届くか」を確認 → 届くなら 4 (Playwright で実 mouse event を inject する方法) を探求 → 届かないなら 1 (LSI Software RAID) → 2 (OEM Redfish) → 5 (MEGACLI live CLI) の順で試行。
