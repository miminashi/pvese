## 再現方法

各サーバ N (11/12/13) について、概略以下のフロー:

```sh
# 1. 事前確認 (BMC 認証 + Redfish PowerState)
ipmitool -I lanplus -H 10.10.10.3X -U claude -P Claude123 chassis status
./scripts/bmc-power.sh status 10.10.10.3X claude Claude123

# 2. BIOS LSI HBA OPROM Enabled 化 (bios-setup スキル)
./pve-lock.sh wait ./oplog.sh ./scripts/bmc-power.sh forceoff 10.10.10.3X claude Claude123
sleep 15 && ./pve-lock.sh wait ./oplog.sh ./scripts/bmc-power.sh on 10.10.10.3X claude Claude123
# Delete x60 で BIOS 進入 → Advanced > PCIe/PCI/PnP > LSI HBA OPROM → Enabled → F4

# 3. os-setup Phase 1-8
./scripts/os-setup-phase.sh init --config config/server${N}.yml
./scripts/generate-preseed.sh config/server${N}.yml preseed/preseed-generated-s${N}.cfg
./scripts/remaster-debian-iso.sh /var/samba/public/debian-13.3.0-amd64-netinst.iso \
    preseed/preseed-generated-s${N}.cfg /var/samba/public/debian-preseed-s${N}.iso

# 4. VirtualMedia mount + power cycle (CGI; 13号機のみ CSRF 必須)
./scripts/bmc-session.sh login 10.10.10.3X claude Claude123 tmp/<sid>/bmc-cookie-s${N}
# 11/12号機: CSRF 不要 (cookie のみで CGI op.cgi が動作)
# 13号機:
#   CSRF=$(./scripts/bmc-session.sh csrf 10.10.10.33 tmp/<sid>/bmc-cookie-s13)
#   ./scripts/bmc-virtualmedia.sh config/mount with $CSRF
./scripts/bmc-power.sh on 10.10.10.3X claude Claude123

# 5. SOL monitor で installer 完走を待機
.venv/bin/python scripts/sol-monitor.py --bmc-ip 10.10.10.3X --bmc-user claude --bmc-pass Claude123 \
    --log-file tmp/<sid>/sol-install-s${N}.log --max-reconnects 3

# 6. VirtualMedia umount → power on → SSH 待機 (10.10.10.21X)
./scripts/ssh-wait.sh 10.10.10.21X --timeout 240 --interval 10

# 7. (13号機のみ) RTC 時刻同期
NOW=$(date -u +%Y-%m-%dT%H:%M:%SZ); ssh -F ssh/config root@10.10.10.213 "date -s '${NOW}'"

# 8. PVE インストール
ssh -F ssh/config root@10.10.10.21X sh /tmp/pre-pve-setup.sh --dhcp-iface eno1.1120 --static-gw 10.10.10.1 --codename trixie
ssh -F ssh/config root@10.10.10.21X /tmp/pve-setup-remote.sh --phase pre-reboot --hostname ayase-web-service-${N} --ip 10.10.10.21X --codename trixie --serial-unit 1
ssh -F ssh/config root@10.10.10.21X reboot
./scripts/ssh-wait.sh 10.10.10.21X --timeout 300 --interval 10
ssh -F ssh/config root@10.10.10.21X /tmp/pve-setup-remote.sh --phase post-reboot --hostname ayase-web-service-${N} --ip 10.10.10.21X --codename trixie --serial-unit 1 --linstor
ssh -F ssh/config root@10.10.10.21X reboot
./scripts/ssh-wait.sh 10.10.10.21X --timeout 300 --interval 10

# 9. ブリッジ設定
ssh -F ssh/config root@10.10.10.21X sh /tmp/pve-bridge-setup.sh \
    --vlan-iface eno1 --internet-vlan-id 1120 --internal-vlan-id 1083 --static-ip 10.10.10.21X/8
```

## 副次知見・トラブル

### 1. Nutanix BMC FW バージョン差による Redfish/CGI 挙動差

| FW | Redfish | CGI CSRF |
|----|---------|----------|
| 10号機 (3.65) | trailing `/` どちらも 200 | 必須 |
| 11/12号機 (3.63) | trailing `/` 必須 (なしは 301) | **不要** (古い世代) |
| 13号機 (新版) | 1.3.0 (どちらも 200) | **必須** |

- `bmc-power.sh` / `bmc-virtualmedia.sh` の curl に `-L` を追加し、3 機種すべてで Redfish が動作するよう修正
- CGI CSRF は CGI の世代差 (世代 A: 11/12号機 = no token / 世代 B: 10号機 + 13号機 = token 必須)

### 2. 12号機 BIOS Boot Mode は **UEFI**

10/11/13号機が LEGACY (出荷時 default) なのに対し 12号機のみ UEFI。preseed/`remaster-debian-iso.sh` は dual-boot ISO を生成するため、UEFI モードでも Debian installer は正常に起動し grub-efi-amd64 が install された。VLAN 構成と PVE 動作は LEGACY/UEFI で同等 (verification 結果一致)。

### 3. 13号機 RTC バッテリ劣化

- インストール直後の OS 時刻: 2025-09-04 (実時刻 2026-05-02)
- `/etc/machine-id` mtime: 2015-01-04 (BIOS RTC が出荷時刻にリセットされる挙動)
- 結果: Phase 6 の machine-id false-positive ガードが false negative を返す
- 対処: `date -s` で OS 時刻を手動同期 → apt-get GPG 検証エラー回避 → pre-pve-setup と post-reboot を完走
- **将来対策**: `pre-pve-setup.sh` 冒頭に `date -s` または chronyd 強制同期を追加すれば手動介入不要。10号機の前任残タスクと同根

### 4. `bios-setup` スキルでのナビゲーション操作の取りこぼし

12号機 BIOS で `ArrowDown x16` が `x14` 効果しか発生せず (LSI HBA OPROM の 1 つ上 = CPU2 SXB1 OPROM を誤って Legacy → EFI に変更)。
- 復旧: Save & Exit タブ → Discard Changes でロールバック → 再ナビゲート → LSI HBA OPROM のみ正しく Enabled に変更 → Save
- 教訓: BIOS ナビゲーションは canvas focus 喪失や key drop で稀に行数がズレる。ステップごとに screenshot 確認 + help text による位置検証 (例: "Enable/Disable LSI HBA firmware to be loaded") が必須

### 5. 並列実行で時間短縮

12号機 SOL monitor 中に 13号機 BIOS 操作、12号機 Phase 7 中に 13号機 Phase 5 SOL monitor を background 化することで、3 台直列の単純合計 (~94分) のうち約 15 分を吸収できた。BMC は機体ごとに独立しているため並列の制約なし。
